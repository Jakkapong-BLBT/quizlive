# QuizLive — ระบบตอบคำถามเรียลไทม์ (แบบ Kahoot / AhaSlides)

ผู้เล่นไม่ต้องติดตั้งแอปหรือสมัครสมาชิก — สแกน QR หรือใส่ PIN 6 หลัก แล้วใส่ชื่อก็เล่นได้ทันที
ทดสอบแล้วรองรับผู้เล่นพร้อมกัน 100 คน (และ 300 คน) ตอบพร้อมกันได้โดยไม่มีคำตอบตกหล่น

## ความสามารถ
**ผู้จัด (หน้า `/host.html`)**
- สร้าง / แก้ไข / ทำสำเนา / ลบ แบบทดสอบ — คำถามแบบ 2–4 ตัวเลือก, ถูก/ผิด, เฉลยได้หลายข้อ
- ตั้งเวลาแต่ละข้อ (5–120 วินาที), คะแนนปกติ / x2 / ไม่คิดคะแนน, ใส่รูปภาพ (ลิงก์หรืออัปโหลด)
- **วางคำถามจาก Excel** ได้ทีละหลายข้อ (ดูไฟล์ `แม่แบบคำถาม.csv`)
- ส่งออก / นำเข้าแบบทดสอบเป็นไฟล์ .json (สำรองหรือย้ายเครื่อง)
- หน้าจอสำหรับฉายขึ้นจอ: QR + PIN, รายชื่อผู้เล่นที่เข้ามา, ล็อกห้อง, นำผู้เล่นออก
- ระหว่างเกม: นับถอยหลัง, จำนวนคนที่ตอบแล้ว, กราฟสรุปคำตอบ, % ตอบถูก, อันดับ Top 5 หลังแต่ละข้อ
- จบเกม: Podium อันดับ 1–3 + พลุ, ตารางอันดับทั้งหมด, สรุปรายข้อ, **ดาวน์โหลดผลเป็น CSV (เปิดด้วย Excel ได้ภาษาไทย)**
- ปุ่มลัด: `Space` / `Enter` = ไปขั้นถัดไป

**ผู้เล่น (หน้าแรก `/`)**
- ปุ่มตอบ 4 สี 4 รูปทรงแบบ Kahoot (เลือกได้ว่าจะแสดงข้อความคำถามบนมือถือด้วยหรือไม่)
- เห็นผลทันทีว่าถูก/ผิด, คะแนนที่ได้, ตอบถูกติดกัน (streak), อันดับปัจจุบัน และตามหลังใครอยู่กี่คะแนน
- เน็ตหลุด / เผลอรีเฟรช → กลับเข้าเกมเดิมได้อัตโนมัติ คะแนนไม่หาย

**การคิดคะแนน (เหมือน Kahoot)** ตอบถูกได้ 500–1,000 คะแนนตามความเร็ว (ตอบทันที = 1,000, ตอบตอนหมดเวลา = 500) ตอบผิด = 0
ถ้าคะแนนเท่ากัน คนที่ใช้เวลาตอบข้อที่ถูกรวมน้อยกว่าได้อันดับดีกว่า

## วิธีนำขึ้นใช้งาน

### ทางเลือก A — ขึ้นคลาวด์ (แนะนำสำหรับใช้งานจริง 100 คน)
ใช้บริการที่รัน Node.js ได้ เช่น **Render.com** (มีแพ็กเกจฟรี)
1. อัปโหลดโฟลเดอร์นี้ขึ้น GitHub (repository ใหม่)
2. ที่ Render: **New → Web Service** → เลือก repository
3. ตั้งค่า Build Command: `npm install` • Start Command: `npm start`
4. กด Deploy → จะได้ลิงก์เช่น `https://quizlive-xxxx.onrender.com`
5. ผู้จัดเปิด `https://.../host.html` • ผู้เล่นสแกน QR ที่ขึ้นบนจอ

> แพ็กเกจฟรีของ Render จะ “หลับ” เมื่อไม่มีคนใช้สักพัก ให้เปิดหน้า host ก่อนเริ่มกิจกรรมสัก 1–2 นาทีเพื่อปลุกเครื่อง
> (หรือใช้แพ็กเกจแบบเสียเงินที่ไม่หลับ) ใช้ได้เช่นกันกับ Railway, Fly.io, หรือเซิร์ฟเวอร์ของบริษัทที่มี Node.js 18+

### ทางเลือก B — รันบนโน้ตบุ๊ก (ใช้ในห้องอบรม Wi-Fi เดียวกัน)
1. ติดตั้ง Node.js (https://nodejs.org เวอร์ชัน LTS)
2. เปิด Terminal / Command Prompt ในโฟลเดอร์นี้ แล้วพิมพ์
   ```
   npm install
   npm start
   ```
3. เปิด `http://localhost:3000/host.html` บนโน้ตบุ๊ก
4. ผู้เล่นต้องใช้ IP ของโน้ตบุ๊ก เช่น `http://192.168.1.25:3000` — ให้ผู้จัดเปิดหน้า host ผ่าน IP นี้ (ไม่ใช่ localhost) QR บนจอจึงจะชี้ไปถูกที่
> Wi-Fi บริษัท/แขกบางแห่งบล็อกการเชื่อมต่อระหว่างเครื่อง และ access point เดียวอาจรับมือถือ 100 เครื่องไม่ไหว — สำหรับงานใหญ่แนะนำทางเลือก A

## เคล็ดลับการใช้งาน
- แบบทดสอบเก็บไว้ใน **เบราว์เซอร์ของเครื่องผู้จัด** → กด “ส่งออก” เก็บไฟล์ .json ไว้เสมอ
- ผลคะแนนอยู่ในหน่วยความจำของเซิร์ฟเวอร์ระหว่างเกม → **ดาวน์โหลด CSV ก่อนกด “ปิดห้อง”**
- ถ้าเผลอปิดแท็บผู้จัด ให้เปิด `/host.html` ในแท็บเดิม/เบราว์เซอร์เดิมอีกครั้ง ระบบจะพากลับเข้าเกม
- ใช้ชื่อแบบ “ชื่อ-แบรนด์/สาขา” เพื่อให้ดูผลรายบุคคลได้ง่าย

## ทดสอบโหลด
```
npm install
node loadtest.js 100            # จำลองผู้เล่น 100 คนบนเครื่องตัวเอง
node loadtest.js 100 https://quizlive-xxxx.onrender.com   # ทดสอบกับเซิร์ฟเวอร์จริง
```

## โครงสร้างไฟล์
```
server.js          เซิร์ฟเวอร์ (Express + Socket.IO) — จัดการห้องเกม, เวลา, คะแนน, อันดับ
public/host.html   หน้าผู้จัด: คลังแบบทดสอบ, ตัวแก้ไข, หน้าจอเกม
public/index.html  หน้าผู้เล่น (มือถือ)
public/style.css, public/common.js
loadtest.js        สคริปต์จำลองผู้เล่นพร้อมกัน
แม่แบบคำถาม.csv     แม่แบบสำหรับพิมพ์คำถามใน Excel แล้ววางเข้าระบบ
```
